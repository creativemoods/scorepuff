# ScorePuff branding

**Ratings that pop.**

Use the happy cream popcorn mascot, deep purple surfaces, white “Score” and golden “Puff”. The rating plaque uses a gold star, one white average /10 score, a gold outline and a deep purple fill. IMDb and Rotten Tomatoes remain inputs to the average; their separate source badges are not used.

| Token | Colour |
| --- | --- |
| Background | `#190A2B` |
| Dark purple | `#160823` |
| Purple highlight | `#4C156A` |
| Card surface | `#2D1C3D` |
| Gold | `#FFCC00` |
| Text | `#FFF8FF` |
| Muted text | `#DDCFE6` |

`mascot.png` is the shared transparent illustration. SVG masters reference this adjacent file; keep them together when editing or exporting. PNG exports are standalone. App icons include a 512 × 512 master and 192, 144, 96, 72 and 48 pixel variants. The feature graphic is 1024 × 500. Horizontal and stacked logos have purple backgrounds.

The Android launcher uses an adaptive foreground/background and an Android 13 monochrome variant. Native settings and the offline playground share the same colour theme. Overlay badges retain their 32 × 20 dp size and 3 dp artwork inset; loading and ambiguity indicators remain distinct. The “8.6” on the mascot is decorative sample artwork, not a live rating.

The project website is https://creativemoods.pt/scorepuff. The Android package and APK filenames are unchanged.
